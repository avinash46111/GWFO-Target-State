# Citi WFM — Collections Forecasting Platform

Workforce management forecasting tool for USPB Collections with AI-powered scenario analysis.

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to Netlify

1. Push to GitHub
2. Go to app.netlify.com → Add new site → Import existing project
3. Connect your repo — Netlify auto-detects netlify.toml
4. Click Deploy
